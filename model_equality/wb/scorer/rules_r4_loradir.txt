R4 PRE-REGISTERED RULES: directional test for a weak LoRA (loradir.py)
Written 2026-11-21 19:40 CET, before any surrogate adapter is trained and before any directional
statistic is computed on any endpoint. Nothing below was tuned on ref-09, ref-01 or the lures.

Data: wb/in/ledger_snapshot_20261121T1940_s5.jsonl (copy of the local ledger at 19:40, 1642 ref- responses,
read only). Model SmolLM2-360M-Instruct, float32, default chat template (default system prompt), login
Quadro card 0, <= 10 GB. No API request.

1. Surrogate direction (fit on the strong siblings only)
   LoRA rank 8, alpha = rank, all linear projections (q,k,v,o,gate,up,down), dropout 0.05, AdamW,
   12 epochs, cosine schedule, loss = cross-entropy at T = 0.7 on the response tokens (end token included
   when the response stopped). Tied scales: ref-04 is modelled as B + 0.7 dW, ref-07 as B + 1.5 dW.
   Budget parity: per strong endpoint only the 100 responses with the smallest sha1("train|" + id):
   20 validation, 80 training. Candidates: learning rate 5e-4 and 1.5e-3. Kept: the (learning rate, epoch)
   with the largest validation gain (mean over the two endpoints of the per-token log-likelihood gain over
   the base at T = 0.7 on their validation rows). No other endpoint enters the fit or the selection.

2. Scoring: every ref- endpoint and LOCAL (wb/ref_local/SmolLM2-360M-Instruct/from_ref-01_x2_T0.7_s0.jsonl,
   334 base samples at T = 0.7 generated earlier by mescore.refgen). Directions: s0.3, s0.7, s1.5; nuisance
   contexts nosys (template without system prompt), helpful ("You are a helpful assistant."), nova (the
   twin's system prompt); T grid 0.6 0.65 0.7 0.75 0.8 0.9 1.0 1.1.

3. Primary statistic
   Target s0.3, nuisance = T only, T = the endpoint's own base-likelihood maximiser on the grid (same rows).
   Rows = all responses whose probe category is not 'diag' (D*, E01_identity*). Reason fixed a priori: on
   identity probes a hidden system prompt and the LoRA both erase the default identity (R3: lures reach
   z ~ 2 there), so these probes cannot separate weights from context. Tokens flagged ALT_SEG dropped.
   z_mart = D / sqrt(Var) (martingale null, no reference), z_emp = same sum, empirical row variance.
   An endpoint is FLAGGED (weak-LoRA direction present) iff z_mart >= 4 and z_emp >= 4.

4. Success criteria
   a. ref-09 FLAGGED on all its rows.
   b. Parity: random subsets of 100 responses of ref-09 (all categories, then the row filter), 2000 draws:
      report median z_mart, median z_emp, P(flagged). Usable at parity iff P(flagged) >= 0.9.
   c. Calibration: ref-01 and LOCAL have |z_mart| < 3.
   d. Lures ref-03, ref-05, ref-06, ref-08 PASS iff not flagged, on all rows and with P(flagged) <= 0.01
      at parity. Strict pass: min(z_mart, z_emp) < 3.
   e. ref-02 (fp8) reported, expected not flagged. ref-04 and ref-07 reported on the rows NOT used for the
      fit (71 each), expected flagged.
   Rule usable for ep- iff a, b, c and d hold.

5. Secondary, reported without decision: nuisance = T + the 3 contexts; fixed T = 0.7 without projection;
   all categories; per category; H1 half (sha1(id) mod 2 = 1, as R2/R3); S1 (excess surprise at T = 0.7, the
   existing statistic) on the same rows, one-sample and two-sample against ref-01; relative z against
   ref-01 and LOCAL; profile-likelihood strength s_hat (expected 0.3 / 0.7 / 1.5 for ref-09 / 04 / 07).

6. If a criterion fails it is reported as failed. Any variant chosen after seeing these results is
   exploratory and has to be confirmed on new ref- responses.
